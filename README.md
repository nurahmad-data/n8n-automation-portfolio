# n8n Automation Portfolio

A version-controlled ledger of my workflow automations, demonstrating progression from foundational deterministic logic to advanced API orchestration.

## Repository Architecture
* **Phase 1:** Foundations (Core nodes, basic routing)
* **Phase 2:** Deterministic Logic (Switching, merging, data transformation)
* **Phase 3:** Connectivity & APIs (External webhooks, HTTP requests)
* **Phase 4:** Agentic AI (LLM integration, autonomous routing)

## Methodology
Workflows are built and tested on a local Dockerized n8n instance, exported as JSON, and version-controlled here to demonstrate structural engineering capabilities.
